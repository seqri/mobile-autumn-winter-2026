# Lab 01: мини-спека useState-счётчика (ДЗ после пары 1)

Цель: учебный экран-счётчик на useState.

Стек и ограничения: Expo + TypeScript; только useState + StyleSheet; без сторонних библиотек.

Готово, если:
- число по центру, старт с 0
- кнопка + увеличивает на 1
- кнопка − уменьшает на 1, но не ниже 0
- кнопка Reset сбрасывает в 0
- код можно объяснить на защите

Не делаем: сохранение в AsyncStorage, сервер, анимации, Redux/Zustand.

Полная версия спеки к паре 3 — `lab-usestate.md`.
